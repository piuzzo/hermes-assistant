Privacy Policy

Hermes Assistant · last updated 18 October 2026

Who uses this app

Hermes Assistant is a self-hosted personal assistant used only by its owner. It is not offered to the public.

Data accessed

With the owner's explicit consent through Google OAuth, the app accesses the owner's Google Calendar (scope https://www.googleapis.com/auth/calendar) to list, create and delete calendar events. No other Google data is accessed.

How data is used and stored

  • Calendar data is used only to answer the owner's requests.
  • The OAuth token is stored only on the owner's own device and is never shared.
  • To process a request, the relevant calendar information may be sent to the AI model provider configured by the owner.
  • Data is not sold, used for advertising, or shared with any other third party.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account → Third-party apps. Revoking access and deleting the token on the device removes all stored credentials.

Contact

Questions can be submitted as an issue in the project repository.
